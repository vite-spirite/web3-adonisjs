AdonisJS v6 provider for EVM blockchain interaction using viem with first-class wallet and contract support.

- Provide configurable Web3 service for mainnets, testnets, and local nodes via providers.
- Simplify wallet creation, message signing, transactions, and balance queries.
- Enable smart contract deployment, read/write calls, and real-time event listeners.
- Add Ace commands to scaffold contracts and sync on-chain data to database.
